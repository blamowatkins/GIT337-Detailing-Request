F5 · State and Recovery Specimen

This section demonstrates the form's default, focus, required, valid, invalid, disabled, and server-returned error states. Required fields must be completed before submission. Errors identify the affected field and explain how to correct the problem. Optional fields remain neutral when left empty.

Form State Guide

  • Default: Fields display neutral borders before interaction.
  • Focus: Keyboard focus uses a visible gold outline.
  • Required: Required fields must be completed before submission.
  • Valid: Valid entries can display a green border.
  • Invalid: Invalid entries can display a red border and must provide helpful correction instructions.
  • Disabled: Disabled controls cannot be activated.
  • Server-returned error: The fictional example below identifies an email problem and explains how to correct it.
